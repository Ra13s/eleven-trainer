# Sources and licensing

Eleven Trainer's original code and documentation are released under the [MIT license](../../LICENSE). Imported settings are separate data. Loading a file or producing a reordered copy does not make its underlying content MIT licensed.

## Community work that informed the project

- [Dynamic Drillinator / ElevenBallMachine](https://github.com/shanelindsay/ElevenBallMachine) demonstrates community experimentation with ball-machine sequences. No code or JSON from that repository is included here.
- [ETT Service Return Drills](https://github.com/jerryfromearth/ETT-Service-Return-Drills) provides community serve-return resources. Its repository license must be evaluated for any particular material reused; this project does not bundle it.
- [SolidSlime's 4008.1/4008.2 announcement](https://solidslime.net/2025/09/free-eleven-table-tennis-ball-machine-drills-4008-1-for-new-physics/) describes downloadable right- and left-handed drill packs updated for newer physics. Those current cloud packs are not bundled here.

Free in-game availability and permission to redistribute a source dataset are different questions. The current packs may include work by multiple authors and may differ from older GitHub files. Keeping them separate avoids treating a license found on one repository as permission for every related cloud export.

This initial release imports the player's own local settings. Contributors who propose bundled drills should supply the exact source/version, permission or license, required notices, authorship and a reproducible calibration record. Until then, documentation links to community resources without copying their payloads.

## Platform documentation

Setup instructions were checked on 2026-11-01 against [Meta Device Setup](https://developers.meta.com/vr/documentation/native/android/mobile-device-setup/), [Meta's device testing guide](https://developers.meta.com/vr/documentation/android-apps/enable-developer-mode/), [Android ADB documentation](https://developer.android.com/tools/adb), and [Platform Tools downloads](https://developer.android.com/tools/releases/platform-tools). These external instructions can change independently of this project.

The documentation structure follows [Diátaxis](https://diataxis.fr/). Its distinction between learning, completing tasks, looking up facts and understanding design is the reason setup steps and architecture rationale live on separate pages.
